# Bike Sales Analysis – Interactive Excel Dashboard

An interactive Excel dashboard project designed to analyse customer purchasing behaviour and identify patterns influencing bike purchases. The project uses data cleaning, customer segmentation, Pivot Tables, lookup functions, and interactive visualizations to explore purchasing trends across different demographic and behavioural categories.

### Key Features
- Data cleaning and standardization using Microsoft Excel.
- Customer segmentation based on age, income, occupation, gender, and marital status.
- Age group classification using Excel IF formulas.
- Data analysis using Pivot Tables.
- Data lookup using VLOOKUP and XLOOKUP.
- Interactive dashboard with charts and Slicers.
- Comparison of bike purchase behaviour across regions and customer segments.

### Tech Stack
Microsoft Excel | Pivot Tables | VLOOKUP | XLOOKUP | IF Functions | Slicers | Data Visualization

### Objective
To analyse customer purchasing patterns, identify high-purchase segments, and provide insights that can support data-driven sales and marketing decisions.
